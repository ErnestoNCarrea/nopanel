# Coding

- Prefer functional approaches when possible
- Use Protocol-based DI pattern
- Use interfaces and pluggable backends when applicable

## Testing instructions

- Add or update tests for the code you change, even if nobody asked.
- Fix any test or type errors until the whole suite is green.
- Run tests with: `python -m pytest --tb=short -q`

## Documentation

- Maintain pages and navigation in `docs/` and `mkdocs.yml`
- Always update documentation when making changes
- Be comprehensive but very succinct and to the point
- Prefer tables and lists over long paragraph text
- When making code decisions, add succinct comments with justification
